# Urban Threadz

A responsive online clothing store built with HTML, CSS and JavaScript. The application allows users to browse clothing products, explore product details, create an account, log in and manage their shopping cart. Developed as a frontend e-commerce project, it demonstrates responsive web design, dynamic product rendering, user authentication and Firebase integration.

## Features

- **Product Browsing:** Browse clothing products displayed in a responsive layout.
- **Dynamic Product Rendering:** Load and display product information dynamically.
- **User Authentication:** Register and log in using Firebase Authentication.
- **Shopping Cart:** Add products to the cart and manage selected items.
- **Responsive Design:** Optimised layouts for different screen sizes.
- **Firebase Integration:** Use Firebase and Firestore for application data management.
